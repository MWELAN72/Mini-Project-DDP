# Sistem Pendataan Jadwal Rilis Game
Program ini dibuat untuk mengelola data jadwal rilis game.
Data yang disimpan terdiri dari nama game, platform, dan tanggal rilis.
Program menggunakan list sebagai tempat penyimpanan data dan tuple untuk setiap data game.

# Fitur Program
Program memiliki 4 operasi utama:
- Menambahkan data game
- Menampilkan data game
- Mengubah data game
- Menghapus data game

Program menggunakan menu berulang dengan `while` sampai pengguna memilih menu keluar.
