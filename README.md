# Sistem Pendataan Jadwal Rilis Game

Program ini dibuat untuk mengelola data jadwal rilis game. Data yang digunakan terdiri dari nama game, platform, dan tanggal rilis.

Program memiliki beberapa menu, yaitu:
1. Tambah data game
2. Lihat data game
3. Ubah data game
4. Hapus data game
5. Keluar

Program menggunakan list dan tuple untuk menyimpan data sementara serta menggunakan perulangan while agar menu dapat digunakan berulang sampai memilih menu keluar.
